# Changelog

## 0.9.5

- Desktop packages for macOS Apple Silicon, Windows x86-64, and Linux ARM64.
- Consistent version and contact information in the application and package metadata.
- Improved command-line `--help` and `--version` behavior.

## 0.9.4

- Windows and Linux desktop shells using the shared core and interface server.
- Tray integration and platform-specific background-process controls.
- Windows file-change notifications and portable installation scripts.

## 0.9.3

- Missing-files-only recovery without overwriting existing files.
- Notification history and recovery actions in the interface.
- Live configuration reload for the background observer.

These are early releases. Linux packages have been executed in the build environment; Windows and macOS packages require native validation. See [platform details](PLATFORMS.md) and [limitations](LIMITATIONS.md).
